# はじめに

このフォルダには、会議の議事録と文字起こしが自動で並びます。中身は持ち主の Mac が書き、直されると自動で置き換わります。ここで直しても次の更新で元に戻るので、直したいときは持ち主に伝えてください。

## フォルダの見方
- 「会議の一覧」 — 会議の一覧です。新しい順に、日付・時刻・相手先・種類・題・一行の要約が並びます
- 「議事録」フォルダ — 年ごとに、会議 1 件につき 1 つの議事録があります
- 「文字起こし」フォルダ — 議事録と同じ名前の末尾に「_文字起こし」が付いた、発言の全文です

## 読み方
1. まず「会議の一覧」で、日付と相手先から会議を探す
2. 議事録を読む。本文の「（→ 00:07:08）」は会議の中の時刻で、文字起こしの「[00:07:08]」の発言に当たります（同じ文字で検索できます）
3. 言い回しまで知りたいときだけ、文字起こしを読む
- 取り込んだ録画の文字起こしは、話者がすべて「不明」になります。誰の発言かは前後から読み取ってください
- 議事録の出席者と担当は、自動で推し量ったものを含みます

## Claude に読ませるとき
このフォルダを Claude につなぎ、「はじめに を読んでから、会議の一覧 → 議事録 → 文字起こし の順に読んで」と頼んでください。

## 録画する人の手順
1. 録画の名前を **日本時間** の `日付_時刻_相手先_用件` にする（例: `2026-12-02_1000_サンプル商事_トライアル打合せ.mp4`）。相手先の名前に `_` を使わない。形式は {{exts}} のどれか（ほかのファイルは受け取り箱に置かない）
2. 録画の受け取り箱に置き、持ち主に一言伝える
3. 「議事録が並びました」の知らせ（持ち主が決めた方法で届く）が来たら、{{keep_days}} 日以内に、受け取り箱の録画と、録画の道具の側に残る元の録画を消す（ゴミ箱も空にする）

## 決まり
- 録画は {{keep_days}} 日で消す。議事録と文字起こしは消さない
- 顧客の発言をこのフォルダの外に写さない
