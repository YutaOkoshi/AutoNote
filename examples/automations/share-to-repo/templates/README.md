# 会議の記録

会議の議事録と文字起こしを置く場所です。見られるのは招かれた人だけ（非公開）。ファイルは持ち主の Mac のスクリプトが書きます。

## フォルダの見方
- `INDEX.md` — 会議の一覧（日付・時刻・相手先・種類・題・一行の要約）。新しい順
- `<年>/<日付>_<時刻>_<題>.md` — 議事録
- `<年>/文字起こし/<議事録と同じ名前>_文字起こし.md` — 文字起こしの全文

## Claude への案内
1. まず `INDEX.md` で、日付と相手先から会議を絞る
2. `<年>/` の議事録を読む。本文の「（→ 00:07:08）」は会議の中の時刻で、文字起こしの `[00:07:08]` の行に当たる（同じ文字で検索できる）
3. 言い回しまで要るときだけ、`<年>/文字起こし/` の同じ名前のファイル（末尾が `_文字起こし`）を読む
- 取り込んだ録画の文字起こしは、話者がすべて「不明」になる。誰の発言かは文脈から推し量り、断定しない
- 議事録の出席者と担当は、Claude の推測を含む
- frontmatter の `kind` は `customer`（顧客との会議）か `internal`（社内）、`customer` は相手先

## 録画する人の手順
1. 録画の名前を **日本時間** の `日付_時刻_相手先_用件` にする（例: `2026-12-02_1000_サンプル商事_トライアル打合せ.mp4`）。相手先の名前に `_` を使わない。形式は {{exts}} のどれか（ほかのファイルは受け取り箱に置かない）
2. 録画の受け取り箱（共有フォルダ）に置き、持ち主に一言伝える
3. 「議事録が並びました」の知らせ（持ち主が決めた方法で届く）が来たら、{{keep_days}} 日以内に、受け取り箱の録画と、録画の道具の側に残る元の録画を消す（ゴミ箱も空にする）

## 決まり
- 録画は {{keep_days}} 日で消す。議事録と文字起こしは消さない
- ここにあるファイルは GitHub の画面で直さない（自動で作り直される）。直したいときは持ち主に言う
- 録画・音声はここに置かない
- 顧客の発言をここの外に写さない
